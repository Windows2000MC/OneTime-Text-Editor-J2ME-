# OneTime-Text-Editor-J2ME-
OneTime Text Editor is an utility application for J2ME Phones and also Emulator [.e.g J2ME Loader]. This app uses High level UI (also known as Form ui) which doesn't required high-end phones. This is a normal text editor but it can save you text in 2 ways, RMS and FileConnection. You can take full control over your text.
